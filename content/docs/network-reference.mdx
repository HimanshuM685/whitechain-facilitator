Public RPCs are rate limited to roughly 50 requests/second per IP with some burst headroom. If you are running your own facilitator at volume, use a dedicated endpoint.

## Adding the chain to viem

<NetCode filename="chain.ts">
{`import { defineChain } from "viem";

export const whitechain = defineChain({
  id: {{chainId}},
  name: "{{networkName}}",
  nativeCurrency: { name: "WhiteBIT Coin", symbol: "WBT", decimals: 18 },
  rpcUrls: { default: { http: ["{{rpc}}"], webSocket: ["{{wsRpc}}"] } },
  blockExplorers: { default: { name: "Whitechain Explorer", url: "{{explorer}}" } },
  testnet: {{network}} === "testnet",
});`}
</NetCode>

## Explorer APIs

Both explorers are Blockscout, so the v2 JSON API is available and useful for building your own views:

<NetCode lang="bash">
{`# Token metadata
curl -s '{{explorer}}/api/v2/tokens?q=USDC' | jq

# Verified source and ABI for any contract
curl -s '{{explorer}}/api/v2/smart-contracts/{{asset}}' | jq '.name, .abi'

# Transactions for an address — e.g. our facilitator signer
curl -s '{{explorer}}/api/v2/addresses/0xSigner/transactions' | jq`}
</NetCode>

That last one is how you can audit our gas spending independently of the figures we report.
